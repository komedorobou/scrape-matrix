 1. システム概要
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  複数のブランド中古品ECサイトから商品データを一括取得・集約・分析する
  Webアプリケーション。

  対象サイト:
    🔴 セカンドストリート (2ndstreet.jp)    — 国内最大級リユースショップ
    🏷️ トレジャーファクトリー (trefac.jp)   — 総合リユース
    🏪 コメ兵 (komehyo.jp)                  — ブランド買取販売大手
    👔 RAGTAG (ragtag.jp)                   — デザイナーズブランド専門

  主な用途:
    - ブランド品の市場価格調査
    - 在庫・流通量の把握
    - 競合サイト間の価格比較


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
 2. 技術スタック
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  [フロントエンド/UI]
  ────────────────────────────────────────────────────
  Streamlit (>=1.30.0)
    - サイドバー: 検索条件入力（ブランド名・サイト選択・カテゴリ）
    - メインエリア: 進捗表示・統計ダッシュボード・データテーブル
    - カスタムCSS: グラスモーフィズムデザイン
    - セッション管理: st.session_state によるデータ永続化

  [バックエンド/言語]
  ────────────────────────────────────────────────────
  Python 3.11
    - メインアプリ: app.py（約3,200行）
    - 全機能を単一ファイルに集約

  [スクレイピング — 多層フォールバック方式]
  ────────────────────────────────────────────────────
  レイヤー1: ScraperAPI         — プロキシ回転・Cloudflare突破（有料API）
  レイヤー2: curl_cffi          — Chrome 131のTLSフィンガープリント偽装
  レイヤー3: cloudscraper        — Cloudflare JAR方式バイパス
  レイヤー4: undetected-chromedriver — ヘッドレスChrome（Bot検知回避）
  レイヤー5: requests + Cookie   — 標準HTTPクライアント

  ※ 上位レイヤーが失敗した場合、自動的に次のレイヤーへフォールバック

  [HTMLパース]
  ────────────────────────────────────────────────────
  BeautifulSoup4 — HTML解析・商品データ抽出

  [データ処理]
  ────────────────────────────────────────────────────
  pandas          — DataFrame操作・集約・Excel出力
  numpy           — 数値計算（KDE価格分析）
  openpyxl        — Excelファイル書き出し

  [並列処理]
  ────────────────────────────────────────────────────
  ThreadPoolExecutor (concurrent.futures)
    - 最大10ワーカーで商品詳細ページを並列取得
    - スレッドローカルセッションで接続管理
    - 200件単位のバッチ処理

  [ブランド名検索]
  ────────────────────────────────────────────────────
  WEAR API (api.wear2.jp)  — ブランドカタログ検索
  DuckDuckGo HTML          — Web検索フォールバック
  Brave API                — 代替Web検索

 3. 主要機能
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  [一括スクレイピング]
  - 最大999ページまでの全件取得
  - 複数サイト同時スクレイピング
  - リアルタイム進捗表示

  [再開・レジューム機能]
  - 既存データからスタートページを推定して高速再開
  - 20ページ連続スキップで自動終了判定
  - 中間保存（10ページごと）でクラッシュ耐性

  [件数チェック]
  - スクレイピング前にサイト別の該当件数を事前確認
  - 不足分だけ再取得する差分スクレイピング

  [価格分析]
  - KDE（カーネル密度推定）による代表価格算出
  - 最安値・最高値・平均価格の統計表示
  - 価格帯フィルタリング（デフォルト¥10,000以上）

  [データエクスポート]
  - Excel形式（.xlsx）ダウンロード
  - サイト別シート分割
  - 抽出項目: URL、商品名、ブランド、型番、品番、素材、カラー、
              サイズ、価格、カテゴリ、取扱店

  [セッション保護]
  - /tmp/scrape_backup.pkl へ自動バックアップ（1時間有効）
  - ブラウザリロード時の自動復元

  [Bot対策回避]
  - User-Agent ローテーション
  - Cookie管理・自動リフレッシュ
  - リクエスト間隔のランダムディレイ（1〜2秒）
  - リトライロジック（最大3回）

  [メモリ最適化]
  - ページごとのGC（ガベージコレクション）
  - Chrome ドライバー定期再起動
  - 大量データのバッチ分割処理
